Tarocchi は、iPhone の中のタロットデッキです。デッキに尋ねる問いは個人的なものなので、このページでは、アプリが何を知っていて、それがどこにあり、誰が見られるのかをはっきりお伝えします。

I要点

  • 問いの文面は、問いの確認とリーディングの作成のためだけに Anthropic のモデル Claude に送られます。名前や過去の展開は含まれません。
  • アナリティクスは自前のものです。イベントを見られるのはアプリの運営者だけです。外部のアナリティクスや広告はなく、データを販売することもありません。
  • IP アドレスはアナリティクスのためには保存されず、そこから国だけを取り出します。サインインのときは、不正利用を防ぐために最大1時間アドレスを保持します。
  • アカウントを削除すると、サーバー上のデータも iPhone の日記も、すべてが消去されます。

IIデータの責任者

Tarocchi アプリとこのサイトは、個人開発者 Ilya Manenkov が運営しています。連絡先：flyyyxxxy@gmail.com。

問いとリーディング

デッキに書いた問いは、iPhone と、私たちのサーバー上のコピーに保存されます。日記がなくならず、新しい iPhone にも移せるようにするためです。問いを確認し、並べ方を提案し、リーディングを書くために、サーバーは Anthropic のモデル Claude に必要最小限のもの、つまり問いの文面、展開、カード、言語を送ります。指で書いた問いは、まずモデルがその線の画像から読み取ります（「手書き」を参照）。名前も、識別子も、過去の展開も送りません。問いを何かの学習に使うことはなく、ほかの人に見せることもありません。

問いとリーディングの文面が、サーバーのログ、エラーメッセージ、アナリティクスに入ることはありません。データベースにアクセスできるのは、サーバーとアプリの運営者だけです。

アナリティクス

アプリは私たちのサーバーにイベントを送ります。どの画面が開かれ、どんな操作が行われたか（たとえば「展開を始めた」）、アプリと iOS のバージョン、iPhone の機種、端末の言語と地域、App Store のストアフロントと国です。国は IP アドレスから、ローカルの DB-IP Lite データベースで割り出します。アドレスそのものは保存しません。問い、リーディング、メモ、検索の文面がイベントに入ることはありません。

アナリティクスは、アプリの何がうまくいき、何がうまくいっていないかを知るために役立ちます。常にオンで、個別のスイッチはありません。イベントはアカウントに結びついていますが、ほかのアプリやウェブサイトをまたいで利用者を追跡するためには使われず、誰とも共有されません。そのため、Apple のトラッキングの確認は表示されません。

クラッシュ

アプリがクラッシュしたりエラーが起きたりすると、次に起動したときにレポートが私たちのサーバーに送られます。エラーが起きた場所、バージョン、デバイスです。利用者が書いたものは何も含まれません。iPhone の設定で許可している場合は、Apple が独自のクラッシュレポートを開発者と共有することもあります。

手書き

指で書いた問いは、モデル Claude（Anthropic）が読み取ります。問いをデッキの下に置くと、iPhone は線の画像（色も背景もないシンプルな画像）を私たちのサーバーに送り、サーバーはそれを問いの確認とあわせてモデルに渡します。返ってくるのは読み取られた一行で、利用者が直すこともできます。サーバーはこの画像を保存せず、ログやアナリティクスにも書きません。線そのものは問いと一緒に残るので、封筒と日記にはご自身の筆跡がそのまま残ります。

Apple でサインイン

アカウントは最初は匿名です。Apple でサインインすると、サーバーは Apple が提供する識別子を保存します。それによって、新しい iPhone でも日記が見つかります。Apple から受け取る名前やメールアドレスは、サーバーには保存しません。

サブスクリプション

購入は App Store を通じて行われます。サーバーは、購入を確認するサービス RevenueCat からサブスクリプションの状態を受け取ります。アプリが支払い情報を目にすることはありません。

IVデータを受け取る相手

  • Anthropic — 問いの文面（または読み取りのための手書きの画像）、展開、カード、言語。モデル Claude が問いを確認し、リーディングを書くためです。私たちは一般向けの製品ではなく API を使っています。TODO：私たちの契約における Anthropic の API リクエストの保存期間 — 公開前に記入。
  • Apple — 通知（APNs）、天気（WeatherKit）、Apple でサインイン、購入。
  • RevenueCat — サブスクリプションの状態と、Tarocchi のアカウント識別子。

データを販売することも、広告ネットワークに渡すこともありません。アプリに広告はありません。

VI保存期間

  • 日記、問い、リーディング — 利用者が削除するか、アカウントを削除するまで。
  • 燃やした問いは、手書きも含めて、iPhone とサーバーからただちに完全に削除されます。データベースのバックアップからは、バックアップが入れ替わるにつれて、30日以内に消えます。
  • アナリティクスの生のイベント — 25か月、その後に削除。集計した数値（たとえば1日に何回展開が行われたか）は期限なく保存されますが、誰にも結びついていません。
  • 79枚目のカードの刷り — アカウントを削除するまでサーバーに保存。
  • クラッシュレポートと通知用トークン — クラッシュレポートは90日間。通知用トークンは、60日間使われなければ削除されます。
  • サインインのときの IP アドレス — 不正利用を防ぐため、最大1時間。

VIIアプリの中でできること

  • 問いを燃やす — 日記から。文面と手書きが燃え、日付とカードは残ります。
  • 日記を削除する — 「設定」から。
  • アカウントを削除する — 「設定」→「アカウント」→「アカウントを削除」。サーバー上のデータ、Apple ID と RevenueCat の購入との結びつき、この iPhone の日記と設定、そのすべてが消去されます。アナリティクスのイベントは利用者との結びつきを失います。これは取り消せません。削除せずにサインアウトする方法はありません。アカウントと日記はひとつのものとして存在しています。
  • アカウントを削除しても、サブスクリプションは解約されません。解約は Apple ID の設定で行います。
  • 私たちが保有しているご自身のデータについて問い合わせたいときや、その削除を求めたいときは、flyyyxxxy@gmail.com までご連絡ください。
