Tarocchi คือสำรับไพ่ทาโรต์บนโทรศัพท์ของคุณ คำถามที่คุณถามสำรับเป็นเรื่องส่วนตัว หน้านี้จึงบอกอย่างตรงไปตรงมาว่าแอปรู้อะไร ข้อมูลอยู่ที่ไหน และใครมองเห็นได้

Iโดยสรุป

  • ข้อความคำถามของคุณถูกส่งไปยังโมเดล Claude ของ Anthropic เพื่อตรวจคำถามและเขียนการอ่านไพ่เท่านั้น — โดยไม่มีชื่อของคุณและไม่มีการวางไพ่ครั้งก่อน ๆ
  • การวิเคราะห์การใช้งานเป็นของเราเอง: มีเพียงเจ้าของแอปที่เห็นเหตุการณ์ ไม่มีระบบวิเคราะห์หรือโฆษณาของบุคคลที่สาม และไม่มีการขายข้อมูล
  • ที่อยู่ IP ของคุณไม่ถูกเก็บเพื่อการวิเคราะห์ — นำมาใช้เพียงหาประเทศ ตอนลงชื่อเข้า ที่อยู่จะถูกเก็บไว้ไม่เกินหนึ่งชั่วโมงเพื่อป้องกันการใช้งานในทางที่ผิด
  • การลบบัญชีจะลบทุกอย่าง: ข้อมูลบนเซิร์ฟเวอร์และสมุดบันทึกบนโทรศัพท์

IIIเก็บอะไรและเก็บไว้ที่ไหน

ข้อมูลเก็บไว้ที่ไหนใครได้รับ
คำถามถึงสำรับ — ข้อความโทรศัพท์และเซิร์ฟเวอร์ของเราAnthropic — ตอนตรวจคำถามและเขียนการอ่านไพ่
ลายมือของคำถามโทรศัพท์และเซิร์ฟเวอร์ของเราAnthropic — ภาพของเส้นลายมือ เพื่ออ่านคำถาม เซิร์ฟเวอร์ไม่เก็บภาพนี้ไว้
การอ่านไพ่โทรศัพท์และเซิร์ฟเวอร์ของเราไม่มีใคร
ไพ่ที่จั่วได้และวันที่โทรศัพท์และเซิร์ฟเวอร์ของเราไม่มีใคร
ภาษา เขตเวลา เวลาของไพ่ประจำวันเซิร์ฟเวอร์ของเราไม่มีใคร
โทเค็นอุปกรณ์สำหรับการแจ้งเตือนเซิร์ฟเวอร์ของเราApple (บริการแจ้งเตือน APNs)
ตัวระบุของ Apple — หากคุณลงชื่อเข้าด้วย Appleเซิร์ฟเวอร์ของเราไม่มีใคร
สถานะการสมัครสมาชิกเซิร์ฟเวอร์ของเราRevenueCat และ Apple
ตำแหน่งโดยประมาณ — เฉพาะเมื่อเปิดสภาพอากาศนอกหน้าต่างไม่เก็บApple (WeatherKit) — ในขณะที่ขอข้อมูลสภาพอากาศ
เหตุการณ์การวิเคราะห์: หน้าจอ การกระทำ อุปกรณ์ ประเทศเซิร์ฟเวอร์ของเราไม่มีใคร
รายงานข้อขัดข้อง — ไม่มีเนื้อหาของคำถามหรือการอ่านไพ่เซิร์ฟเวอร์ของเราไม่มีใคร
ที่อยู่ IPไม่เก็บเพื่อการวิเคราะห์ เก็บเพียงรหัสประเทศ ตอนลงชื่อเข้า — ไม่เกินหนึ่งชั่วโมงไม่มีใคร
รูปถ่ายสำหรับไพ่ใบที่ 79ไม่เก็บ: ประมวลผลบนโทรศัพท์ มีเพียงภาพพิมพ์สองสีที่เสร็จแล้วที่ส่งไปยังเซิร์ฟเวอร์ไม่มีใคร
ข้อมูลเซนเซอร์การเคลื่อนไหวไม่เก็บไม่มีใคร

คำถามและการอ่านไพ่

คำถามที่คุณเขียนถึงสำรับถูกเก็บไว้บนโทรศัพท์ของคุณ และมีสำเนาบนเซิร์ฟเวอร์ของเรา เพื่อให้สมุดบันทึกไม่สูญหายและย้ายไปโทรศัพท์เครื่องใหม่ได้ ในการตรวจคำถาม แนะนำรูปแบบการวางไพ่ และเขียนการอ่านไพ่ เซิร์ฟเวอร์ส่งข้อมูลขั้นต่ำไปยังโมเดล Claude ของ Anthropic ได้แก่ ข้อความคำถาม การวางไพ่ ไพ่ และภาษา คำถามที่เขียนด้วยนิ้วจะถูกโมเดลอ่านจากภาพวาดก่อน (ดู “ลายมือ”) ไม่มีชื่อ ไม่มีตัวระบุ ไม่มีการวางไพ่ครั้งก่อน ๆ เราไม่นำคำถามไปใช้ฝึกสิ่งใด และไม่เคยแสดงให้ผู้อื่นเห็น

ข้อความของคำถามและการอ่านไพ่ไม่เคยถูกบันทึกลงในล็อกของเซิร์ฟเวอร์ ข้อความแจ้งข้อผิดพลาด หรือการวิเคราะห์ มีเพียงเซิร์ฟเวอร์และเจ้าของแอปที่เข้าถึงฐานข้อมูลได้

การวิเคราะห์การใช้งาน

แอปส่งเหตุการณ์ไปยังเซิร์ฟเวอร์ของเรา: หน้าจอใดถูกเปิดและมีการกระทำใด (เช่น “เริ่มการวางไพ่”) เวอร์ชันของแอปและ iOS รุ่นโทรศัพท์ ภาษาและภูมิภาคของอุปกรณ์ หน้าร้าน App Store และประเทศ ประเทศถูกค้นหาจากที่อยู่ IP ในฐานข้อมูล DB-IP Lite ที่อยู่ในเครื่อง ส่วนตัวที่อยู่เองไม่ถูกบันทึก ข้อความของคำถาม การอ่านไพ่ บันทึก และการค้นหาไม่เคยถูกใส่ในเหตุการณ์

การวิเคราะห์ช่วยให้เราเข้าใจว่าอะไรในแอปใช้ได้ดีและอะไรไม่ดี การวิเคราะห์เปิดอยู่เสมอ ไม่มีสวิตช์แยกต่างหาก เหตุการณ์เชื่อมโยงกับบัญชีของคุณ แต่ไม่ได้ใช้ติดตามคุณข้ามแอปและเว็บไซต์ และไม่ได้แบ่งปันให้ใคร — นี่คือเหตุผลที่คำขออนุญาตการติดตามของ Apple ไม่ปรากฏ

ข้อขัดข้อง

หากแอปขัดข้องหรือพบข้อผิดพลาด รายงานจะถูกส่งไปยังเซิร์ฟเวอร์ของเราเมื่อเปิดแอปครั้งถัดไป: ข้อผิดพลาดเกิดที่ใด เวอร์ชัน และอุปกรณ์ รายงานไม่มีสิ่งที่คุณเขียนอยู่เลย Apple อาจแบ่งปันรายงานข้อขัดข้องของ Apple เองให้นักพัฒนาด้วย หากคุณอนุญาตไว้ในการตั้งค่า iPhone

ลายมือ

คำถามที่เขียนด้วยนิ้วจะถูกอ่านโดยโมเดล Claude (Anthropic): เมื่อคุณวางคำถามไว้ใต้สำรับ โทรศัพท์จะส่งภาพวาดของเส้นลายมือไปยังเซิร์ฟเวอร์ของเรา — เป็นภาพธรรมดาที่ไม่มีสีและไม่มีพื้นหลัง — และเซิร์ฟเวอร์ส่งต่อให้โมเดลพร้อมกับการตรวจคำถาม สิ่งที่ได้กลับมาคือบรรทัดที่อ่านได้ ซึ่งคุณแก้ไขได้ เซิร์ฟเวอร์ไม่เก็บภาพวาดนี้และไม่บันทึกลงในล็อกหรือการวิเคราะห์ ตัวเส้นลายมือยังคงอยู่กับคำถาม ซองและสมุดบันทึกจึงเก็บลายมือของคุณเองไว้

ลงชื่อเข้าด้วย Apple

บัญชีของคุณเริ่มต้นแบบไม่ระบุตัวตน หากคุณลงชื่อเข้าด้วย Apple เซิร์ฟเวอร์จะเก็บตัวระบุที่ Apple ให้มา — นั่นคือวิธีที่สมุดบันทึกจะพบคุณบนโทรศัพท์เครื่องใหม่ เซิร์ฟเวอร์ไม่เก็บชื่อหรืออีเมลของคุณจาก Apple

การสมัครสมาชิก

การซื้อทำผ่าน App Store เซิร์ฟเวอร์ทราบสถานะการสมัครสมาชิกของคุณจาก RevenueCat ซึ่งเป็นบริการตรวจสอบการซื้อ แอปไม่เคยเห็นข้อมูลการชำระเงินของคุณ

IVใครได้รับข้อมูล

  • Anthropic — ข้อความคำถาม (หรือภาพวาดลายมือ เพื่อให้อ่านได้) การวางไพ่ ไพ่ และภาษา เพื่อให้โมเดล Claude ตรวจคำถามและเขียนการอ่านไพ่ เราใช้ API ไม่ใช่ผลิตภัณฑ์สำหรับผู้บริโภค TODO: การเก็บรักษาคำขอ API ของ Anthropic ตามข้อตกลงของเรา — กรอกก่อนเปิดตัว
  • Apple — การแจ้งเตือน (APNs) สภาพอากาศ (WeatherKit) ลงชื่อเข้าด้วย Apple และการซื้อ
  • RevenueCat — สถานะการสมัครสมาชิกและตัวระบุบัญชี Tarocchi ของคุณ

เราไม่ขายข้อมูลและไม่ส่งต่อให้เครือข่ายโฆษณา ในแอปไม่มีโฆษณา

VIเก็บไว้นานเท่าไร

  • สมุดบันทึก คำถาม และการอ่านไพ่ — จนกว่าคุณจะลบ หรือลบบัญชี
  • คำถามที่ถูกเผาจะถูกลบออกจากโทรศัพท์และเซิร์ฟเวอร์ทันทีและถาวร รวมถึงลายมือ และจะหายไปจากข้อมูลสำรองของฐานข้อมูลเมื่อข้อมูลสำรองหมุนเวียน — ภายใน 30 วัน
  • เหตุการณ์การวิเคราะห์ดิบ — 25 เดือน แล้วจึงลบ ตัวเลขรวม (เช่น จำนวนการวางไพ่ในหนึ่งวัน) เก็บไว้ไม่มีกำหนดและไม่เชื่อมโยงกับใคร
  • ภาพพิมพ์ไพ่ใบที่ 79 ของคุณ — อยู่บนเซิร์ฟเวอร์จนกว่าจะลบบัญชี
  • รายงานข้อขัดข้องและโทเค็นการแจ้งเตือน — รายงานข้อขัดข้องเก็บ 90 วัน โทเค็นการแจ้งเตือนถูกลบหลังจากไม่มีการใช้งาน 60 วัน
  • ที่อยู่ IP ตอนลงชื่อเข้า — ไม่เกินหนึ่งชั่วโมง เพื่อป้องกันการใช้งานในทางที่ผิด

VIIสิ่งที่คุณทำได้ในแอป

  • เผาคำถาม — ในสมุดบันทึก ข้อความและลายมือถูกเผา วันที่และไพ่ยังคงอยู่
  • ลบสมุดบันทึก — ในการตั้งค่า
  • ลบบัญชี — การตั้งค่า → บัญชี → ลบบัญชี ทุกอย่างถูกลบ: ข้อมูลบนเซิร์ฟเวอร์ การเชื่อมโยงกับ Apple ID ของคุณและกับการซื้อใน RevenueCat สมุดบันทึกและการตั้งค่าบนโทรศัพท์เครื่องนี้ เหตุการณ์การวิเคราะห์จะไม่เชื่อมโยงกับคุณอีก การลบนี้ย้อนกลับไม่ได้ ไม่มีการออกจากระบบโดยไม่ลบ: บัญชีและสมุดบันทึกอยู่ด้วยกัน
  • การลบบัญชีไม่ได้ยกเลิกการสมัครสมาชิก — ยกเลิกได้ในการตั้งค่า Apple ID ของคุณ
  • หากต้องการสอบถามว่าเรามีข้อมูลอะไรเกี่ยวกับคุณ หรือขอให้เราลบข้อมูล เขียนมาที่ flyyyxxxy@gmail.com
