ปรับปรุงเมื่อ: 2026-11-17

Tarocchi คือสำรับไพ่ทาโรต์บนโทรศัพท์ของคุณ แอปและเว็บไซต์นี้ดำเนินการโดย Ilya Manenkov นักพัฒนาอิสระ ซึ่งเป็นผู้รับผิดชอบข้อมูล สมุดบันทึกของคุณอยู่บนโทรศัพท์ และมีสำเนาเก็บไว้บนเซิร์ฟเวอร์ของเราที่ Railway ในสหภาพยุโรป (เนเธอร์แลนด์) เพื่อให้สมุดบันทึกไม่สูญหายและย้ายไปโทรศัพท์เครื่องใหม่ได้

Iข้อมูลอะไรและเพื่ออะไร

ข้อมูลเพื่ออะไรใครได้รับเก็บไว้นานเท่าไร
ข้อความคำถาม การวางไพ่ ไพ่ ภาษาเพื่อตรวจคำถามและเขียนการอ่านไพ่Anthropic (โมเดล Claude) โดยไม่มีชื่อของคุณและไม่มีการวางไพ่ครั้งก่อน ๆบนเซิร์ฟเวอร์ — จนกว่าจะลบคำถามหรือบัญชี TODO: ระยะเวลาการเก็บที่ Anthropic ตามข้อตกลง API
ภาพของคำถามที่เขียนด้วยนิ้วเพื่ออ่านคำถามAnthropicเซิร์ฟเวอร์ไม่เก็บ
ไพ่ใบที่ 79: ภาพพิมพ์ ชื่อ ความหมายไพ่ส่วนตัวของคุณในการวางไพ่Anthropic — ชื่อและความหมาย สำหรับการอ่านไพ่ ส่วนภาพพิมพ์ — ไม่มีใครจนกว่าจะลบไพ่หรือบัญชี รูปถ่ายไม่ออกจากโทรศัพท์
สมุดบันทึก: การอ่านไพ่ ไพ่ วันที่สมุดบันทึกไม่มีใครจนกว่าจะลบ
บัญชี: ตัวระบุ ภาษา เขตเวลา และ Apple ID (หากคุณลงชื่อเข้าด้วย Apple)เพื่อหาสมุดบันทึกของคุณบนโทรศัพท์เครื่องใหม่ และส่งไพ่ประจำวันไม่มีใคร เราไม่เก็บชื่อหรืออีเมลของคุณจาก Appleจนกว่าจะลบบัญชี
โทเค็นการแจ้งเตือนการแจ้งเตือนApple (APNs)ถูกลบหากอุปกรณ์ไม่มีการติดต่อเป็นเวลา 60 วัน
การซื้อและสถานะการสมัครสมาชิกเพื่อเปิดการสมัครสมาชิกApple และ RevenueCat — พร้อมตัวระบุบัญชี แอปไม่เคยเห็นข้อมูลการชำระเงินจนกว่าจะลบบัญชี
ตำแหน่งโดยประมาณ — เฉพาะเมื่อเปิดสภาพอากาศสภาพอากาศนอกหน้าต่างApple (WeatherKit)ไม่เก็บ
เหตุการณ์การวิเคราะห์: หน้าจอ การกระทำ อุปกรณ์ ภาษา ประเทศเพื่อเข้าใจว่าอะไรใช้ได้ผล เป็นระบบของเราเอง เชื่อมโยงกับบัญชี แต่ไม่ใช้ติดตามคุณไม่มีใคร25 เดือน ตัวเลขรวมที่ไม่มีตัวระบุ — ไม่มีกำหนด
รายงานข้อขัดข้อง — ไม่มีคำถามหรือการอ่านไพ่เพื่อแก้ข้อผิดพลาดไม่มีใคร90 วัน
ที่อยู่ IPประเทศสำหรับการวิเคราะห์ และการป้องกันการลงชื่อเข้าRailway — ในล็อกคำขอของ Railwayเก็บเพียงรหัสประเทศ ตอนลงชื่อเข้า — ไม่เกินหนึ่งชั่วโมง ในล็อกของ Railway — ตามระยะเวลาของ Railway

ข้อความของคำถามและการอ่านไพ่ไม่ถูกบันทึกลงในล็อกหรือการวิเคราะห์ และไม่ถูกนำไปใช้ฝึกสิ่งใด เราไม่ขายข้อมูล ไม่มีโฆษณาและไม่มีระบบวิเคราะห์ของบุคคลที่สาม ผู้รับข้อมูลคือ Railway (โฮสติ้ง) Anthropic Apple และ RevenueCat ซึ่งอาจประมวลผลข้อมูลนอกสหภาพยุโรป รวมถึงในสหรัฐอเมริกา TODO: ฐานทางกฎหมายในการประมวลผลตาม GDPR (คำถามที่ 19)

IIการลบและสิทธิของคุณ

คุณเผาคำถามได้ในสมุดบันทึก: ข้อความและลายมือจะถูกลบออกจากโทรศัพท์และเซิร์ฟเวอร์ทันที การลบบัญชี — การตั้งค่า → บัญชี → ลบบัญชี: ข้อมูลบนเซิร์ฟเวอร์ การเชื่อมโยงกับ Apple ID และการซื้อ รวมทั้งสมุดบันทึกและการตั้งค่าบนโทรศัพท์จะถูกลบ และเหตุการณ์การวิเคราะห์จะไม่เชื่อมโยงกับคุณอีก ข้อมูลจะหายไปจากข้อมูลสำรองภายใน 30 วัน การลบบัญชีไม่ได้ยกเลิกการสมัครสมาชิก — ยกเลิกได้ในการตั้งค่า Apple ID ของคุณ

หากต้องการทราบว่าเรามีข้อมูลอะไรเกี่ยวกับคุณ หรือต้องการแก้ไขหรือลบข้อมูล เขียนมาที่ flyyyxxxy@gmail.com ในสหภาพยุโรป คุณมีสิทธิตาม GDPR ได้แก่ การเข้าถึง การแก้ไข การลบ การจำกัดการประมวลผล การโอนย้ายข้อมูล การคัดค้าน และการร้องเรียนต่อหน่วยงานกำกับดูแล
